Course Highlights

Computer Networks

CMSC 481 - Spring 2026

In my computer networks course, I studied every layer of the TCP/IP model in detail. I was tested on topics such as time/frequency division multiplexing at the physical layer and NAT protocols for supporting multiple private IPs under a single public IP at the network layer.


I also had some hands on work designing a dictionary server in which clients would send words to the server and the server would respond with a definition if it had one. I coded this server system using python and socket programming techniques in which the client and server communicated over sockets in my device. I also developed multiple versions of this server, some able to handle multiple clients using threading or queueing techniques.

Software Engineering I

CMSC 447 - Spring 2026

My Software Engineering course was designed to be an accurate simulation of working in an AGILE scrum team. It featured lectures educating on the methods and structure of AGILE and also featured a semester long project in which we would plan, design, and develop a software product for a class sponsor.


I was part of a team of 3 whose responsibility was to create an inventory tracking system app / website for a company by the name of COOLSYS. This project consisted of 3 4-week sprints, in which we set realistic user stories with story points for that sprint using Jira. During these sprints I took on the responsibility of writing SRS and Design documents, making visual class design diagrams for the team to use, and designing/implementing the front end UI design using typescript.

Malware Analysis

CMSC 449 - Spring 2026

In my malware Analysis course I not only studied the different methods of malware detection and Analysis but also implement the methods I studied in hands on sandbox environments. During the course I learned in detail about studying malware strings and assembly code, using PE tools to learn more about malicious files, running malware in VMs safely, and learning common methods malware authors use to abstract and obscure their code.


I worked hands on in a VM with real malware to practice techniques such as following assembly code in programs like IDA and Ghidra to understand the function of a program, studying program imports and entropy to determine more about the program, and techniques of finding an entry point of packed files to unpack them.

Principles Of Operating Systems

CMSC 421 - Fall 2025

Principles of operating systems was the most technically complex course I took at UMBC as it went above and beyond what is expected for a typical OS course. In this class, I studied the role operating systems fulfill within a computer as well as the different methods of data/process management that operating systems use to run an OS.


The most technically challenging parts of this course were the projects, which were designed to be less formally structured, and more accurate to real kernelspace dev projects, with a broad objective and little hand holding. During these projects, I worked with a custom Ubuntu linux kernel and use C to code a custom shell, syscalls with threading and child processes, and a filesystem using FUSE. We used git for version control as well as being able to recover project progress in the cases in which something we coded broke the OS (which was common).

Computer Architecture

CMSC 411 - Spring 2026

My Computer Architecture course was focused on the physical logic circuits that are behind the hardware that allow computers to work. In this course we learned about the different components that make up processors, memory, instruction readers, and timers. We developed circuits that could handle basic arithmetic such as bitwise adders, multipliers, dividers, and subtractors as well as circuits that could store binary information to be used later. Using these we would eventually design a small calculator which could execute assembly instructions put in its instruction registry as well as handle these instructions using pipelining.

Principles of Computer Security

CMSC 426 - Fall 2025

In Principles of Computer Security, I primarily studied methods of encryption decryption, and secure data storage, as well as techniques to make code secure from common vulnerabilities. We secondarily learned common exploits such as SQL injection and cross site scripting and were given a custom test websites where we performed said exploits to better understand them and how to prevent them.

Machine Learning

CMSC 478 - Spring 2025

In my Machine Learning course, I studied methods of data analysis using machine learning algorithms such as linear/logistic regression and neural networks. We frequently did assignments to develop the equations for these algorithms from scratch to better understand them, and toward the later end of the course, I developed a neural network using Python in Google Colab. I used Python libraries like numpy, pandas, and dataclasses to break down excel spreadsheets into workable data that can be fed into a neural network. During these assignments, our professor gave us starter code as a foundation to start from, but I would frequently choose to start from scratch to get a better understanding of what I was making. The most advanced program I coded in Machine Learning was a 11-node neural network capable of making predictions about a 50,000 entry Google spreadsheet. I split the data into a training and testing set, and managed to get about 68-76% accuracy during tests I did.
